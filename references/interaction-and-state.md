# 任务、状态与多端

用于有真实操作的页面。先沿用户任务画出最短的“入口 → 选择对象 → 操作 → 可观察结果 → 返回/恢复”，再补会改变决策的状态。沿用现有接口和设计系统，示例不是替换业务的理由。

## 状态先决定能做什么

| 情况 | 保留什么、允许什么 | 避免 |
| --- | --- | --- |
| 首次加载 | 当前入口、加载对象；较慢时提供可识别进度或取消 | 伪装成空列表、无限无说明转圈 |
| 后台刷新 | 旧数据与选择，标明更新时间和刷新中 | 清空整屏，让键盘位置丢失 |
| 无数据 | 说明没有对象与可行的创建/导入入口，按权限显示 | 用假的示例数据冒充业务结果 |
| 筛选无结果 | 保留条件、显示清除入口 | 把零结果写成系统无数据 |
| 请求失败/离线 | 输入、筛选、位置；解释是否可重试、是否有旧数据 | 对提交超时自动再发写入 |
| 无权查看/操作 | 最少必要的信息和申请/返回路径；服务端仍校验 | 仅靠隐藏按钮实现权限 |
| 部分成功 | 成功对象的确定结果、失败对象与原因 | “全部成功”、重发已成功项 |
| 写入结果未知 | 请求标识、核实入口、受影响对象；按接口读回 | 把未知改成失败或成功，盲目重试 |
| 未保存 | 本地草稿与服务器版本区别，明确保存/放弃 | 因界面减法删除真实状态 |

危险操作提供明确的二次确认或可用的撤销窗口；对象、影响与恢复边界看得见。筛选、标签页、分页状态写入 URL 并支持直达/返回，不能把秘密或敏感输入塞进 URL。长文本、多语言撑长、空值、零与上限值在真实容器试用，不补造业务数据。

失败是用户的当前位置，不是重开任务。刷新、关闭/返回、角色变化、长内容会不会使人丢掉已完成步骤？只对相关风险补检查；不为每个页面机械造全状态矩阵。

## 电脑、手机与键盘

- 动作用原生 `button`，导航用带目标的链接；原生控件不重复绑定 Enter/Space 触发同一次动作。自定义控件才补必要键盘语义。纯图标操作要有可访问名称，名称与实际动作一致；有意义的图片提供替代文本，装饰图片用空 `alt` 或明确隐藏，不重复播报图标。
- 标题按内容层级组织，不从 h1 直接跳到 h3 来获得想要的字号；字号由样式决定。长页给键盘用户可达主内容的入口，锚点、焦点和错误定位都避开固定栏。异步结果按重要性使用状态/警告区域，不把每次普通更新都设为强制打断。
- 在电脑上明确主要工作区和就地操作；窄屏优先让对象与当前任务完整呈现。主从可变为列表/详情两屏，返回恢复原查询、选择和滚动位置。
- 表格若必须比较列，允许**表格区域**横向滚动，保留行标题和必要操作；不能把整页撑宽。不是所有表格都该变成卡片。
- 窄容器与窄视口分别检查；长中文、长 ID 和无空格字符串不靠固定高度裁掉。状态不能只靠颜色；控件命名与可见标签一致。
- 用 Tab/Shift+Tab 走主要路径，Enter/Space 激活，Esc 退出可取消层；焦点可见、不被 sticky 区挡住。快捷键不能截走输入框的编辑键。
- 路由/详情切换后把焦点放在新标题或合适入口；返回交还触发者。异步反馈使用适当的状态/警告区域，不让每次后台刷新抢焦点。
- 异步操作用键盘实测“触发前 → 请求中 → 完成/失败 → 下一次 Tab/Shift+Tab”，记录实际焦点和可见焦点环。禁用或替换有焦点的按钮可能让焦点落回 body；结束后保持原入口可见可达，必要时恢复到原控件或合适的结果入口，并播报状态。用户在等待中已主动移到别处时不抢回焦点。仅有 `:focus-visible` 样式或程序调用 `focus()` 不能替代这条操作取证。
- 100% 检查实际阅读尺寸，200% 用真实浏览器缩放检查重排。高 DPR 截图不能替代；手机 CSS 视口不能冒充实机。

触屏按手势需要设置 `touch-action`，弹层内部用 `overscroll-behavior` 避免滚动传到底页；照顾 `safe-area`，不禁止用户缩放。日期/数字按语言地区用 `Intl` 格式化，深色主题声明合适的 `color-scheme`，让原生控件一起适配。

队列先按用户主要判断依据组织：对象与具体观察先于经办人和次级动作。手机从页顶走到首个可判断对象，核对品牌、层级、汇总与筛选各自的定位或操作收益；合并重复上下文，让对象与对照依据更早进入阅读，不按固定像素位置裁决。关联记录的依据可就近呈现，或通过可辨识的链接/按钮进入；既要能用键盘到达，也要看得出可以操作。桌面/手机都实际核对对象、依据和下一步，而非仅检查无溢出。

## 跨页对象与状态连续

从实际入口记录“对象标识、当前状态及来源、筛选/选择、返回位置”，打开详情后逐项读回，再检查刷新、返回及相关异常入口。同一对象不能换编号或混入另一条记录；未核实不能在下一页变成已完成；重读得到的新状态可变化，但要能解释来源与时点。返回按任务恢复原条件、选择和位置，不能只核对两页用了同一色板。

主操作、对象标记和状态用语在相关页面可识别，路由后焦点与结果能接上。可以用共享记录头、编号、标题或对象形态帮助确认；不强制把详情做成实物，也不强制转场动画。采用转场时仍要直接可达、刷新可用，减少动态效果时保持相同对象、状态和操作路径。
