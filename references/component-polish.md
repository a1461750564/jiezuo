# 单组件精修与结构原型

先固定组件承担的对象、主动作、容器宽度、已有 tokens 和相邻组件；以相同内容比较修改前后。不要为了局部精修更换整页方向。

组件形态、状态反馈、变体或 token 用法缺少合适的项目范例、需要比较具体做法时，先按组件名称和当前缺口查 [资料检索](tools.md#按需检索设计与实现资料) 的 `implementation` 领域；已有合适依据则直接沿用。

按影响排序：任务是否可完成 → 状态与语义 → 字体/对齐/间距 → 边框/图标/触感。检查默认、交互中、禁用/只读及本组件真正会遇到的空/加载/失败/选中状态；没有业务意义的状态不强造。长中文、长 ID、320px 容器、键盘焦点和真实浏览器 200% 是不同检查点。处理状态不能只改颜色。

先删重复边框、嵌套面板和重复标签，再判断主动作有没有更突出。图标命中区可大于图形；hover 不得成为唯一入口。过渡可中断，快速反向操作从当前进度接续，减少动态效果时保持结果与可达性。

## 外观与微交互参考（按需）

命中外部作品入口后，确需补充具体形态或反馈做法时，再按组件类型和已定风格在 [Uiverse](https://uiverse.io/) 搜索，先看选中作品的实际状态，再读作品代码或 [Galaxy 源码归档](https://github.com/uiverse-io/galaxy)。只取适合当前对象与主动作的形态和反馈，适配项目已有 tokens、组件接口与业务状态。

社区单元素样例不代表完整业务交互或生产验收；接入后沿用本节已有的状态、键盘与减少动态效果检查。按需引用具体作品，不整库引入；复制代码时保留来源与适用许可，见 [第三方说明](../THIRD_PARTY_NOTICES.md#uiverse--galaxy)。

## 19 套独立结构

[cards.html](../assets/prototypes/cards.html) 提供可运行代码；编号是本项目独立分类，不是官方 Pro 内部库。只选适合对象与操作关系的原型，复用现有组件和状态归属，不能把组件库的展示网格复制成产品卡墙。

| ID | 信息关系 | 主动作 / 关键状态 |
| --- | --- | --- |
| C01 下一项队列 | 优先级、对象摘要和下一步 | 处理当前项；待处理/已处理 |
| C02 对象概览 | 标识与多项键值属性 | 展开详情；默认/详情 |
| C03 审批决策 | 理由与互斥决定 | 同意/退回；决定后锁定 |
| C04 后台任务 | 进度、阶段与恢复 | 暂停/继续/失败重试；完成 |
| C05 文件交付 | 文件预览、格式与产物 | 下载明确的合成文本 |
| C06 活动时间线 | 事件的时间先后 | 展开历史 |
| C07 消息回复 | 发送者、原消息与回复 | 输入并发送；保留回复 |
| C08 方案比较 | 互斥选项及差异 | 单选确认 |
| C09 趋势指标 | 当前值与时间背景 | 切换范围，不能用孤立数字假装趋势 |
| C10 异常处置 | 严重性、影响与确认 | 确认知悉，不伪装成已修复 |
| C11 步骤清单 | 子任务与完成比例 | 独立勾选，反馈进度 |
| C12 空态起步 | 缺少对象时的下一步 | 创建本地草稿 |
| C13 证据检索 | 来源、命中与解释 | 展开原始依据，保留待核实语义 |
| C14 预约时段 | 时间占用与替代选择 | 改期并读回新时段 |

## 使用条件

这些原型只演示合成数据和本地状态。C16 的本地重试计数不是服务端幂等证明，真正提交恢复见 [表单与浮层](forms-and-layers.md)。计数、下载或“已确认”要说清确认的是本地示例还是业务结果。代码复制后继续使用项目真正的数据源、权限、错误恢复和组件库。
