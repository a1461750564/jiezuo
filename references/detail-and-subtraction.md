# 反默认套路、细节与逐句减法

用于明确的精修、自检与整页收尾；局部任务只检查受影响区域。下面是当前支持的网站、工作台、组件与游戏的核对范围，不是所有页面必须采用的风格。每项记实际问题或有依据的不适用，不能只勾选“通过”。

## 反默认自查

| 检查 | 判断依据 / 保留条件 |
| --- | --- |
| 默认左右分栏、同构区块连续复读 | 按对象、信息与主操作的关系判断；说服页的分栏或卡片排若只是可替换外壳就重排，有内容依据则保留；已锁定的业务骨架不擅改 |
| 每层套卡、KPI 卡墙、到处描边 | 对象/比较关系需要边界才保留；删边框后是否仍能分组 |
| 装饰彩色边线、无来由渐变/发光 | 是否表达状态/品牌或确实是获准特效；不能用特效补空洞内容 |
| 大标题 + 空泛短句 + 无对象 CTA | 标题是否回答对象与价值，动作能否预知去向 |
| 系统字体轮换冒充方向、品牌只靠按钮色 | 未锁定时检查实际字体、构图、素材差异；已锁品牌按例外保留字体/色板 |
| 英文眉标、假编号、空洞填缝字 | 是否帮助导航与识别；装饰/制作说明移出产品 |
| 同一权重、满屏状态胶囊、语义色失控 | 主对象、异常与下一步能否快速扫描；状态不用颜色单独传达 |
| 首屏精致、详情/错误/页尾退回默认组件 | 用同一字阶、tokens、操作与状态语义贯穿；相关内页也看 |
| 伪图表、缩小到不可读的截图、无出处证据 | 与真实任务/来源对应；合成、估计、未知明确标注 |
| 只在 hover 出现关键动作、假禁用/假成功 | 键盘与触屏能否完成；写入结果须读回，不按视觉推断 |
| 为显复杂强加动效、布局跳动、滚动劫持 | 是否服务反馈/空间关系；可中断，减少动态效果仍能完成任务 |
| 机械删字、删掉真实边界 | 含义、状态与风险是否保留；不能把“知悉”改成“修复” |

## 100% 实际阅读与 200% 重排

100%：查看实际大小的正文/中文换行/孤字、数字/单位、字重层级、行高、图标基线、间距与对齐、颜色对比、触控命中区、焦点、长内容及滚到页尾后的操作；不是把大图缩进预览来判断字号。

200%：用浏览器原生缩放并记录缩放前后窗口、CSS 视口、DPR/scale 与返回 100% 的结果。核对内容无丢失、焦点/错误不遮挡、主动作可达、浮层可退出、表格仅区域横滚、固定栏不压最后一项。`@2x` 只检查像素细节，缩小视口 + DPR 2 只能称模拟。工具做不到真实缩放时标记未验证，不改判定。

功能文字也检查实际阅读尺寸：按钮、标签、表格、时间码及普通span里的姓名、数值、状态都不能因不是长正文而漏检；数字阈值是提示，不是 WCAG 的字号标准。对局部裁切、浮层出界或覆盖文字，打开受影响状态再看；整页不横滚不能证明容器内没有丢内容。合法的表格区域滚动、未展开层、后续阶段和模态背景按当前状态保留。截断重要内容时有可达的完整入口，不用 `overflow:hidden` 把问题藏掉。

工具报告中复杂背景、原生控件、未访问状态与扫描上限均有边界。未检查或绘制未知就记未验证；零命中不是全项通过。误报保留原提示、当前截图和保留理由，不通过删状态、放宽事实或改规范来清零。

细节放大图用于看描边、图标和基线；如果由放大图片发现问题，再回到实际阅读大小判断影响。高密度图清晰不代表重排可用。

## 逐句删字：保留信息，再压缩表达

按标题、说明、字段提示、反馈和页尾逐句问：对象、当前状态、依据、下一步，删掉哪一项会改变决策？删除前后各读一遍，明确缩短了什么，保留了什么。

同一事实跨区块出现时，按 `事实 | 出现位置 | 此处用途/新增信息 | 保留或合并的理由` 核对，手机整页也实际读一遍。身份确认、状态边界、就近操作提示和必要回顾可以重复；相邻区块只是整组复述、没有新的依据或动作时才合并。不限制出现次数，不按文本匹配自动删句；固定文案与“待核实”等真实边界仍保留。重复不代表跨页状态矛盾，后者另按 [交互与状态](interaction-and-state.md#跨页对象与状态连续) 检查。

| 原句 | 可采用 | 不采用的改法 / 原因 |
| --- | --- | --- |
| “为了给您提供更为良好的体验，请您点击下方按钮保存当前设置” | “保存设置” | 保存有未说明后果时仍需保留后果提示 |
| “提交已发送，当前结果尚待核实，请不要重复提交” | “结果待核实，请先查单” | “提交成功”：发送不证明业务成功 |
| “当前内容为本机草稿，还没有保存到服务器” | “本机草稿 · 未保存到服务器” | “已保存”：混淆草稿和正式保存 |
| “预计耗时约 3 分钟，实际以处理完成为准” | “预计 3 分钟” | “3 分钟后完成”：把估计改成承诺 |
| “这是一组为演示准备的合成数据” | “合成数据” | 全删：示例会被误认为真实业务 |
| “你已知悉此告警，问题仍待排查” | “已知悉 · 待排查” | “已解决”：改变实际状态 |

删掉重复 panel、空洞统计与无意义装饰后，主对象与主动作应更清楚；如果只是变空而无助任务，应重新检查信息组织，而不是继续减少字号和内容。

浏览器原生细节也随设计：文本选中色、光标颜色、滚动条、可见焦点环、链接下划线偏移与数据表格等宽数字。复用系统/组件库的有效默认，不为统一外观损害高对比、键盘或原生行为。

正常的读屏专用隐藏标签保留语义；仅在可见尺寸/裁切提示中排除，不按类名一概豁免。可见的同名元素和意外裁切仍需核对。
