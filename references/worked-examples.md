# 从任务到结果的完整示范

入口按概念跨核心区块/后续页面延续、说服证据、队列定位/详情、混合结果恢复直达对应 CASE。涉及这些结构时，先读该例的决策、边界与完整路径，再只看当前操作相关的实现片段；局部明确修改不展开。借构图、层级或完成度时，先看 CASE 已附的实际画面，把观察转为当前任务的选择；缺少相关画面或涉及交互时再运行对应页面/状态。只借状态协议与恢复逻辑时，读对应流程和实现即可。把可迁移的对象/状态关系及不适用部分写进已有方向说明，不能只写“已参考”。示范教选择过程，不是强制版式、业务数据或新项目模板。均为本项目历史生成产物的教学副本，原评审只适用于原件；教学版未新盲评。

各例共享的过程是：事实与保护契约 → 对象/状态关系 → 结构选择与取舍 → 完整操作 → 多端与失败检查。只迁移当前任务需要的关系，沿用实际项目的组件、tokens和业务语义。运行说明、源码出处与教学版差异都在各例CASE.md/SOURCE.json；不是新的9分认证。
