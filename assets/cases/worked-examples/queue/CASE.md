# 榆岚巡检：观察优先与返回

这是使用合成巡检记录制作的教学副本，展示对象与观察先于经办人及次级动作的组织方式。来源哈希与教学改动见 [SOURCE.json](SOURCE.json)；本副本没有独立评分。

## 任务与保护契约

快速筛出待复核，读到YL-203“开合两次后仍偶发卡住，现场保留原位”，打开同一对象详情后返回。四条事实见[records.json](records.json)，保持原编号、观察、经办人与状态。没有提交、维修或保存后端，不把查看说成完成。

## 从判断依据到结构

桌面保持设施/编号、经办人、观察、状态与详情列的稳定关系；手机先对象，再观察/状态，让主要判断依据先于经办人与详情按钮。筛选贴近标题，避免独占一大块把内容挤出首屏。有效队列不需要为了辨识度改成装饰卡片。

| 选择 | 在本例帮助什么 | 迁移时如何判断 |
| --- | --- | --- |
| 查询后直接接观察列表 | 边定位边读到卡住的现象与待复核状态 | 从手机页顶检查直到首个可判断对象的整段路径；品牌/汇总/筛选各有用途时保留，同义上下文合并 |
| 明确的详情入口与返回焦点 | 用户看出可打开哪条记录，关闭后接着处理 | 关联对象可直接给依据，或给看得出可操作的入口；DOM可聚焦不等于外观已经表达操作 |

本例不提供所有排期或比较任务的答案。当前任务若要对照多个对象，先确定必须同时看见的依据，再决定详情与关联入口；不用固定首项像素位置或一律删除页头来替代这个判断。

## 视觉关系怎样落到代码

本例的结构、样式与事件都在 [index.html](index.html)，颜色变量定义在页内 `:root`，不需要额外的样式导入。下面解释现有实现的对应关系，帮助把设计选择落到实际元素上：

| 视觉关系 | 变量或选择器 | 代码怎样表达 |
| --- | --- | --- |
| 画布、记录与详情属于同一套界面 | `--paper`、`--surface`、`--ink`、`--muted`、`--line`；`body`、`.detail-button`、`#drawer` | 画布用 `--paper`；按钮与详情用 `--surface`；主文字、辅助文字与分隔分别复用对应角色，详情不另换一套配色 |
| 对象与观察先于辅助信息 | `.record-id`、`h3`、`.observation`、`.owner` | 编号用等宽字，设施名用 18px/600，观察保留正文色和独立列；经办人是另一列，手机移到观察之后。层级同时来自字重、位置和阅读顺序 |
| 详情动作可辨认，反馈跟着控件 | `.detail-button`、`.detail-button:hover`、`:focus-visible` | 按钮默认用表面色、描边和动作色；悬停时以 `--accent` 作底并切为白字；键盘焦点用独立轮廓显示，不靠改变记录状态表示操作反馈 |
| 状态既能扫到，也能读懂 | `.record-status`、`.status-dot`、`.done`、`--soft` | 圆点与文字共同表达待复核/已完成；已完成降低字重和颜色强调。手机状态增加浅底，但状态含义仍由原文字保留 |
| 窄屏改变阅读关系，详情保持同一对象 | `.column-head, article`、`.facility`、`.observation`、`.owner`、`.detail-button`、`#drawer` | 1000px 以下先收紧列宽与间距；760px 以下改为对象/状态、整行观察、经办人/详情三行，抽屉从 520px 改为全宽，不把桌面五列一起缩小 |

这里只部分颜色使用了变量；字阶、间距、部分边框和焦点环仍是直接声明值，不是完整 Token 系统或通用数值标准。迁移时把这些关系映射到当前项目已有的 tokens 和组件，保留对象、依据、动作与状态之间的关系，不照搬本例的色值、字号或断点。

## 完整路径与代码

[index.html](index.html)内的records、applyFilter/restoreFilter与详情事件分别负责数据、过滤及对象打开。可直达`?status=pending`，刷新恢复筛选；打开YL-203 → 核对观察 → Esc或关闭 → 返回原触发按钮。教学版补URL筛选状态；原布局和records.json未改。浏览器历史仅恢复已在URL中的状态，未声称完整跨会话滚动恢复。

## 取舍与不适用

复用已成立的行结构和原生select/dialog，避免引入第二套控件。主任务是反复定位与查看，适合队列/详情；复杂批编辑、跨资源排程不能套这页。少量四行是演示规模，不能据此声称大数据性能已验。

## 运行与证据

使用已有 Node 在本目录运行 `node server.mjs`，打开打印地址的/index.html。本地只读合成数据，不安装依赖。核对筛选、直达/刷新、详情/Esc/焦点及手机布局；私有历史检查资料不随包分发，不作为当前宿主的验收结果。
